# Leak Detection for Liquid-Cooled PCBs — Presentation

10-slide deck on best-practice leak detection for liquid-cooled PCBs and cold plates in datacenter systems, covering rope/cable sensors, interdigitated PCB traces, point sensors, and capacitive sensors — compared by reliability, cost, and integration.

## Generate the .pptx

```bash
pip install python-pptx
python build_leak_detection_deck.py
```

Outputs `leak_detection_liquid_cooled_pcb.pptx` in the current directory.

## Pre-built deck

A pre-built copy of the presentation is included in this folder as `leak_detection_liquid_cooled_pcb.pptx`.
